参考实现说明：带标记的可编程恢复

这里所有输入都是合成协议。模型同时包含开放量子系统、经典探测器、读出测量分支和已设定的恢复时钟。不能将一个 readout 列表先平均为单一量子通道再丢弃分支：其量子态与恢复时间相关。

令 M_ab,q(t)=E[N^a C^b rho_q(t)]，保留 a+b<=3 的十个原始计数矩。每段构造含 emission、bath、暗触发、电子读出的完整瞬时生成元 L。对真实发射增量，用二项式展开 (N+1)^a；对电子读出增量，用 (C+1)^b。对应低阶矩源项分别来自发射超算符 Jn 和总读出超算符 Jc。分支 b 的读出映射为 bandwidth*K_b rho K_b†，求和得到总映射。完备关系保证读出的总离开率是 bandwidth。

一个控制段从 a 开始，分支的 base、slope 为 u、v。读出时刻 s 生成的 dead 部分在 r(s)=(1+v)s+u-va 恢复。由于 1+v>0，每个段与分支内可以反解 s=(t-u+va)/(1+v)。这只对 s 落在对应源段内有效；必须累加所有有效源段、源分支。不同源窗口可以重叠，不能只查询最近的一个，也不能假设按进入 dead 的顺序恢复。

设 B_ab,b(s) 是在 s 经该测量分支进入 dead 的矩阵通量，已经包含 C 增加一次的二项式组合。恢复通量为 P_dead,N(t,s) B_ab,b(s)/(1+v)。分母是从读出时刻密度到恢复时刻密度的变量变换因子。P_dead,N 同时传播量子态与真实发射计数的原始矩，使用从 s 到 t 之间实际经过的各控制段；不能只用源段参数或当前参数。恢复通量从 dead 扣除并加入 ready，因此恢复不改变总态的迹，也不增加计数。

初始 dead 部分单独处理：它在 initial_dead_remaining 时作确定性转移，转移前先沿实际控制历史传播所有 N 矩。这个部分不是一次电子读出的后果，不带 C 增量。若剩余时间为零，先转移再输出 t=0。所有观测保持输入顺序，在初始恢复前沿使用右连续值。

no_click 方程保留全部真实发射及 bath，只去掉电子读出的正增益项，保留其离开项。没有读出的新 dead 部分不会产生，只有初始 dead 部分按其时钟转移。首次读出停止态的导数为所有测量分支作用于 no_click 的 pending 块之和；time1、time2 分别累积其迹乘 t、t²。累积后的停止态不再演化，也不做条件归一化。

实现使用短于最小死时间的分段积分保证历史查询已经可用。控制边界、各恢复窗口边界和初始恢复时刻显式划分；DOP853 对区间内部作误差控制。小矩阵指数用经直接 expm 核对的 Chebyshev 插值表加速，该表只近似解析传播矩阵，不替代物理轨迹。最终由原始矩计算协方差和三阶中心联合矩。

隐藏期望值来自另一套下降阶乘矩实现：独立构造事件图，直接矩阵乘法处理跃迁，用 RK45 和 expm_multiply 演化分支历史。它不导入参考实现。除此之外，初始 pending 且无新触发的协议可直接用分支指数等待分布和恢复时刻累计分布求解，固定等待的更新过程与单光子伯努利分布提供额外解析核对。

初始程序保留命令行与基本演化，但用平均无记忆恢复代替已设定时钟，将触发计作读出，使用独立泊松统计并用当前态近似停止态。因此修复需要处理多个独立科学机制，而不是补齐空白程序或修正文法。
